## Ubuntu Distribution Creation and Setup
Open an admin level PowerShell terminal in Terminal. Install latest Ubuntu distro which is Ubuntu-24.04. See command 
below.
```
>: wsl --install Ubuntu-24.04
```
Follow prompts to finish installation. Close and reopen Terminal. You should now see an Ubunut-24.04 terminal option in your terminal options list. In your Ubuntu terminal update and upgrade the package manager.
```
>: sudo apt update
>: sudo apt upgrade
```

### Required Linux packages:
The following Linux packages are required for compiling/running/debugging GridLAB-D.
- build-essential (provides gcc and g++ c/c++ compilers)
- cmake-curses-gui (provides a cmake commandline gui for configuring cmake projects)
- gdb (backend debugger for VS Code)
- git (already comes preinstalled)
- libxerces-c-dev (prerequisite for GridLAB-D)

Here are some optional recommended packages that I use in my dev setup.
- git-flow (tool for streamlining git branch creation)
- gh (github cli tool. See this [link](https://github.com/cli/cli/blob/trunk/docs/install_linux.md) for installation)

You can install everything listest using the following command:
```
>: sudo apt install build-essential cmake-curses-gui gdb git-flow libxerces-c-dev
```

### GridLAB-D Cmake Configure Build Setup.
From the root directory of the repository do the following:
```
>: git checkout --track origin/feature/1478
>: git submodule update --init
>: mkdir cmake-build
>: cd cmake-build
>: ccmake ../
```
Press "C" to configure.
Press "E" to exit when finished.
You can now see all the different Cmake project variables and can set them to your heart's content.
Important ones to point out are:
- CMAKE_BUILD_TYPE: Options are DEBUG or RELEASE.
- CMAKE_INSTALL_PREFIX: default install location is /usr/local (will need to use sudo if installing to default location)
- GLD_USE_HELICS: Toggle ON/OFF to build with HELICS.
if you made any changes to any variable press "C" to configure again.
Press "G" to generate and exit.
To compile the code and install type:
```
>: sudo cmake  --build . --target install (if installing to default location)
```
Verify successful installation by running the autotest script:
```
>: cd ../
>: gridlabd -T 0 --validate
```
Once complete you should see all 661 tests pass.

### VS Code Setup for GridLAB-D
Before opening a VS Code workspace for GridLAB-D make sure you install the extension listed previously.
At the root dir of your repository open vs code:
```
>: code .
```

#### Configuring Cmake
Once opened you need to make sure you install the extensions in the WSL context of VS Code.
You can modify the cmake settings by clicking the cmake icon on the left column menu and click the settings cog wheel in the Project Status row.
I unselect the following for pure preference:
- Cmake: Automatic Reconfigure
- Cmake: Build Before Run
- Cmake: Configure on Edit
- Cmake: Configure on Open

Modify the following:
Cmake: Build Directory - ${workspaceFolder}/cmake-build
Cmake: Install Prefix - ${workspaceFolder}/install

If you want to specify any of the other Cmake project variables like GLD_USE_HELICS you can specify them by clicking the "Edit in settings.json" under the Cmake: Configure Settings then add the cmake variable as the key and the desired user value as the value in the json file. For example:
```
"cmake.configureSettings": {
    "GLD_USE_HELICS": "ON",
    "CMAKE_INSTALL_PREFIX": "${workspaceFolder}/install"
}
```
#### Compiling and installing GridLAB-D
The Cmake Configure/Generation Build/Install process can be kicked off by clicking the build icon on the Build bar under PROJECT STATUS or by clicking the Build icon on the bottom ribbon.
#### Run Configurations
There are two run configurations that you can setup.
- Run autotests (runs fastest with a Release build of the code).
- Debug code (Will only work with a Debug build of the code).

Below is a launch.json that creates the two run configurations:
```
{
    "configurations": [
        {
            "name": "Debug GridLAB-D",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceFolder}/install/bin/gridlabd",
            "args": [
                "${fileBasename}"
            ],
            "stopAtEntry": true,
            "cwd": "${fileDirname}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            "setupCommands": [
                {
                    "description": "Enable pretty-printing for gdb",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                },
                {
                    "description": "Set Disassembly Flavor to Intel",
                    "text": "-gdb-set disassembly-flavor intel",
                    "ignoreFailures": true
                }
            ]
        },
        {
            "name": "Run Autotests",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceFolder}/install/bin/gridlabd",
            "args": [
                "-T",
                "0",
                "--validate"
            ],
            "stopAtEntry": false,
            "cwd": "${workspaceFolder}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            "setupCommands": [
                {
                    "description": "Enable pretty-printing for gdb",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                },
                {
                    "description": "Set Disassembly Flavor to Intel",
                    "text": "-gdb-set disassembly-flavor intel",
                    "ignoreFailures": true
                }
            ]
        }
    ]
}
```
