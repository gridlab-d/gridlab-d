# Setting-Up MSYS2 for Windows
As stated on the [MSYS2 website](https://www.msys2.org/): "MSYS2 is a collection of tools and libraries providing you with an easy-to-use environment for building, installing and running native Windows software." Historically this has been one of the ways that GridLAB-D has been built on Windows and is still the primary way the development team creates the GridLAB-D Windows binaries. 

## Installing MSYS2
Download and installation instructions can by found on the [MSYS2 website](https://www.msys2.org/).

## Launching and Updating MSYS2
MSYS2 can be launched like any other Windows program and presents with a Linux-like command line interface. The first time MSYS2 is launched (and periodically after that), it should be updated

`pacman -Syuu`

After running this the MSYS2 command-line window will close. Re-open MSYS2 and continue the updates by running

`pacman -Su`

## Adding MSYS2 to the PATH variable
Every time MSYS2 is launched, the path to the binaries needs to be added to the PATH variable.

`export PATH=$PATH:/mingw64/bin`
