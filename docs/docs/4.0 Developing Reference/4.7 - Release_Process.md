*NOTE - Dev team does not have installation process well documented (i.e., checking that all installers are functional)*

* Check that installation has no spaces (Gridlab-d 5.3.0 vs Gridlab-d_5.3.0)
* Check that example scripts aren't installed in program files (users do not have permission to edit these files, so users cannot run these sample scripts)

This warning is currently written in the installation instructions:

!!! warning

    The GridLAB-D installer comes with a handful of example files in the share folder, however these cannot be run from the "Programs Files" folder on Windows, as the user does not have permission to write to this location. It is recommended that users move their share folder to their documents and include the path to those files when running, example:

        gridlabd C:\Users\USERNAME\Documents\gridlabd-examples\example.glm
