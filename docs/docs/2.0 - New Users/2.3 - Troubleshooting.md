## Source Code

The final authority and source of truth documentation for all things GridLAB-D™ is the source code. The latest version and exact relationships that comprise GridLAB-D™ are all contained in the [codebase](https://github.com/gridlab-d/gridlab-d/tree/master). For example, for more detail on the house object than what is contained in its [documentation page](../3.0%20-%20Modeling%20Reference/Modules/Residential/2.0%20-%20house-e.md), take a look at its source [code](https://github.com/gridlab-d/gridlab-d/blob/master/residential/house_e.cpp).
