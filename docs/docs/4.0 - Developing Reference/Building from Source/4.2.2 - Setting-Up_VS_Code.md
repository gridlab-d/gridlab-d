# Setting-Up the VS Code IDE
VS Code is the preferred integrated development environment (IDE) for use in developing GridLAB-D™. Many others will work but the documentation will focus on using it.

## Install VS Code
VS Code is no-cost software and can be [downloaded here](https://code.visualstudio.com/download). Binaries are available for macOS, Linux, and Windows.

## Add Extensions
VS Code has MANY extensions that can make GridLAB-D™ development easier. The ones most commonly used by the GridLAB-D™ development team are:

- [C/C++ (Microsoft)](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools)
- [C/C++ Extension Pack (Microsoft)](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools-extension-pack)
- [CMake Tools (Microsoft)](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cmake-tools)
