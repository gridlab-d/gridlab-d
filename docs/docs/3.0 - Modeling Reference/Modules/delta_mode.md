# Delta Mode

## 1.0 Prospective Users
GridLAB-D is also capable of sub-second time-domain simulations, which can offer insight into dynamic transients. This mode of operation is called "Delta Mode", and coexists with the main quasistatic domain simulation mode. GridLAB-D can seamlessly transition between quasistatic and time-domain simulations to take advantage of the benefits each simulation mode offers in different situations.
